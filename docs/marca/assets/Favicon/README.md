# Favicon

- `favicon.svg` — Favicon vectorial; cambia a los colores del tema oscuro con `prefers-color-scheme`. Enlazalo con `<link rel="icon" href="/favicon.svg" type="image/svg+xml">`.
- `favicon-16.png`, `favicon-32.png`, `favicon-48.png` — Respaldo para navegadores sin SVG.
- `apple-touch-icon.png` — 180 × 180, isotipo sobre `surface` (#fbf8f3), para accesos directos en iOS.
- `icon-512.png` — 512 × 512 para el manifiesto web (PWA) y tiendas.

El `favicon.ico` (16, 32 y 48px) se entrega aparte porque este manual no aloja archivos .ico.

> **Nota para este proyecto:** de esta lista solo se incluye `favicon.svg`, en `public/marca/logos/`.
