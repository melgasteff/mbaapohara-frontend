# Etiqueta

Rótulo corto de estado o categoría (`.mb-tag`) y chip de filtro seleccionable (`.mb-chip`).

**Qué aporta quien lo usa:** una o dos palabras; para estados, también un ícono de 14px. Para filtros, un `<button class="mb-chip">` con `aria-pressed`.

| Tono | Clase | Significado |
| --- | --- | --- |
| Éxito | `.mb-tag-success` | Empleo verificado, reseña publicada. |
| Marca | `.mb-tag-yerba` | Anónima, destacada por la comunidad. |
| Advertencia | `.mb-tag-warning` | En revisión. |
| Acento | `.mb-tag-tierra` | Nueva. |
| Peligro | `.mb-tag-danger` | Rechazada (solo la ve quien la escribió). |
| Neutra | `.mb-tag` | Rubro, ciudad. |

- Los estados llevan palabra e ícono, nunca solo color.
- Máximo tres etiquetas por tarjeta.
